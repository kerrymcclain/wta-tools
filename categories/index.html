The state property categories appraisal districts use when they report values to the Comptroller for the School District Property Value Study. Search a code or describe the property (“mobile home on rented land”, “wind turbine”, “warehouse”) to find where it belongs.

Source. Texas Comptroller, Property Classification Guide (Publication 96-313, March 2026), summarized. The guide classifies property for reporting to the Comptroller; it doesn’t decide whether property is taxable or qualifies for special appraisal. Some districts use their own local sub-codes (for example A1, A2), which must map to a valid state category before submitting EARS. Questions about a specific property go to the Comptroller’s Property Tax Assistance Division (800-252-9121, press 1).
